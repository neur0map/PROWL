# Security

Please do not open a public issue for a security problem.

Use GitHub's private report form:

<https://github.com/neur0map/PROWL/security/advisories/new>

Include the affected version, what happened, how to repeat it, and any known
way to reduce the risk. A small example is helpful when it is safe to share.

The `main` branch is the supported line. Older builds may be asked to update
before a fix is prepared.

Prowl may cherry-pick a security fix from Crush when the same problem exists in
both projects. It will not take unrelated upstream changes with that fix.
